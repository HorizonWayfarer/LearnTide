## 第二部分：正文内链的技术判断与改造方案

### 2.1 判断：需要加，但严格限 1-2 条

**结论：在「文末相关阅读」之外，每篇正文内嵌 1-2 条上下文内链。文末区块保留，两者并存。**

理由，按重要性排：

**① 文末区块是模板化 boilerplate，权重折扣显著。** 当前所有内链都渲染在 `<aside class="related">` 里，每篇结构完全一致、位置固定、纯裸锚文本列表。搜索引擎对这类重复出现的模板区块有成熟的降权处理——它更像导航而不是编辑推荐。正文段落里的链接则被视为作者的主动引用，权重传递效率明显更高。

**② 正文链接携带上下文语义。** 文末列表里的「AI 提示词怎么写」，周围只有其他三条链接；同样一条链接放在 041 的「AI 写的小红书文案一眼假」这段话里，周围是「书面语」「无情绪」「无细节」这些词，目标页 052 因此额外获得了一层主题关联信号。这是文末区块给不了的。

**③ 用户行为差异是实打实的。** 文末链接的点击时机在读完之后，此时用户已经获得答案，跳出意图最强。正文内链发生在阅读中途，能截住用户、提升会话深度。对一个新站来说，这类参与度信号比多几条内链更值钱。

**④ 为什么限 1-2 条而不是 3-5 条。** 我们只有 800 字，一共 4-5 个 H2。塞 3 条以上正文链接会出现平均每 200 字一个蓝字的密度，读起来就是内容农场的观感——而「不像内容农场」恰恰是这个站相对 SERP 首页那些今日头条文章的核心差异点。链接策略不该反过来毁掉内容策略。

### 2.3 真正要改的两处

> 交叉引用：SEO 审计附录 R9。该 patch 已由 team-lead 落地于 `qa_check.py:214-223`，`python qa_check.py` 退出码 0、无 traceback，代码层已生效。`FILES` / `ALLOWED_PATHS` 均为模块顶层定义（第 79–93 行），patch 直接命中，无作用域问题（seo-optimizer 已确认）。

```python
# qa_check.py:214-223（R9 落地版，现状）
for _anchor, href in re.findall(r"\[([^]]+)\]\(([^)]+)\)", nocode):
    tgt = href.split("#")[0].split("?")[0].strip()
```

**改动 B（推荐）：`build_articles.py` 的 `inline()` 加 6 行，给外链自动补 rel/target**

当前 `inline()` 对所有链接统一输出 `<a href="...">`，外链不带 `rel` 也不带 `target`。建议：

```python
def inline(s):
    s = esc(s)
    s = re.sub(r"`([^`]+)`", r"<code>\1</code>", s)
    s = re.sub(r"\*\*([^*]+)\*\*", r"<strong>\1</strong>", s)

    def _a(m):                                    # ← 新增
        text, url = m.group(1), m.group(2)        # ← 新增
        if url.startswith(("http://", "https://")):                        # ← 新增
            return '<a href="%s" target="_blank" rel="noopener">%s</a>' % (url, text)  # ← 新增
        return '<a href="%s">%s</a>' % (url, text)                         # ← 新增
    s = re.sub(r"\[([^\]]+)\]\(([^)\s]+)\)", _a, s)                        # ← 替换原有那行
    return s
```

未来上联盟链接时，再加一个约定：URL 末尾带 `#sponsored` 标记的自动输出 `rel="sponsored nofollow noopener"`，并在渲染时去掉标记。这行代码留到真的接联盟时再加，现在不用。

**改动 C（可选，防回归）：给 `build_articles.py` 加一个内链体检输出**

构建时顺手统计每篇的入链数并打印，把「孤岛」和「死胡同」变成构建期就能发现的问题，而不是靠人工审计。核心逻辑十几行：收集所有 `internal_links` + 正文内链，反向计数，入链为 0 的 slug 打警告。这能保证后面 9 批不再出现 081 这种情况。

## 第五部分：外链策略

### 5.1 现状与判断

**全站 17 个页面，外链数量 = 0。** 我逐页 grep 过 `href="http`，一条都没有。

这是需要纠正的认知：**很多人以为不挂外链能「留住权重」。这是 2009 年之前的 PageRank sculpting 思维，早就失效了。** 现在的实际情况是——加 `nofollow` 并不会让那份权重回流到你自己页面上，它只会蒸发。所以「为了保权重不挂外链」是纯亏。

对一个零外链的新域名，往外链接权威来源反而有三重收益：

1. **主题邻域定位**：搜索引擎通过「你引用了谁」来判断你是干什么的。一篇讲提示词的文章链了 OpenAI 官方 prompt engineering 文档和 Anthropic 的文档，等于告诉搜索引擎「这篇和那两篇讲同一件事」。新站没有外部信号，这是少数几个能自己制造的主题信号之一。
2. **E-E-A-T 信任信号**：Brief 里反复强调「内容农场从不写风险提示、从不标更新日期」。同理，**内容农场也从不挂工具官网**——因为他们要留住用户看广告。我们挂，就是一个它们结构上不愿意复制的差异点。
3. **事实可溯源**：本站承诺「价格、免费额度以官网当前说明为准」。既然这么写了，就应该把官网链接直接给出来。不给链接的「以官网为准」是一句空话。

### 5.2 `rel` 属性处理规范（可直接执行）

| 外链类型 | rel 处理 | target | 理由 |
|---|---|---|---|
| **工具官网 / 官方定价页 / 官方文档** | **不加 nofollow**（dofollow） | `_blank` + `rel="noopener"` | 正常引用行为，主题邻域信号，E-E-A-T 正向 |
| **政府法规原文 / 国家标准** | **不加 nofollow** | `_blank` + `rel="noopener"` | 权威度最高的一类来源 |
| **学术论文（arXiv 等）** | **不加 nofollow** | `_blank` + `rel="noopener"` | 同上 |
| **联盟 / 推广 / 返佣链接** | **`rel="sponsored nofollow"`（强制）** | `_blank` + `noopener` | Google 明文要求，不加可能触发人工处罚。本批暂无，但 Brief 提到后期要接联盟，规则先立好 |
| **UGC / 论坛 / 知乎 / 头条** | `rel="nofollow"`，且**尽量不链** | `_blank` + `noopener` | 内容不可控，且这些正是我们要超越的竞品 |
| **竞品内容站** | **不链** | — | 没有链接的理由 |

**`rel="noopener"` 是安全要求**，凡是 `target="_blank"` 都必须加，防止目标页通过 `window.opener` 操作我们的页面。这条没有例外。

**数量规则：**
- 正文外链：每篇 **2-3 条**上限
- **例外**：横评/清单类文章的**对照表格内**，工具名挂官网属于「事实溯源」，不计入正文配额（009 的 6 款、025 的 7 款、039 的 12 款、034 的 5 款）。但必须全部同一格式、全部 dofollow
- 全站硬约束：单页外链总数不超过该页内链总数

### 5.5 零外链现状的破局路径（零预算，务实版）

先说清楚一个前提：**内链只能分配权重，不能创造权重。** 前面所有内链优化做完，站点内部会变得非常健康，但整站的绝对权重仍然由外部链接决定。所以外链是必须解决的，不能靠内链绕过去。

按「性价比 × 可执行性」排序，**不含任何采购**：

**① 可被引用的数据资产（最高价值，中期动作）**
建一个独立页面：**《AI 工具免费额度对照表》**，季度更新、页面显著位置标更新日期、支持按工具/额度类型筛选。

这是中文 AI 领域**最容易被自然引用的资产类型**——别人写文章需要引用「XX 的免费额度是多少」时，会直接链你的表。理由很实在：这类信息变动频繁，没人愿意自己维护，有人维护了大家就都用它。

这一个页面拿到的自然外链，长期看很可能超过 100 篇文章加起来的总和。成本是一次性搭建 + 每季度花半天更新。039 已经有了「三种免费」的分级框架，这个表就是 039 的可交互升级版，内容基本现成。

**② 内容分发带链接（立刻可做，本批就能开始）**
把 052（提示词四段结构）、081（点外卖讲大模型）、041（小红书三步法）改写成知乎回答 / 小红书笔记 / 即刻动态 / V2EX 分享的原生形式，在合适位置放站点链接。

这些平台的外链大多是 nofollow，**但这不是重点**——重点是它们能带来两样东西：真实流量、品牌搜索量。这两个都是间接排名信号，而且对新站尤其重要。

优先做这三篇的原因：052 有可记忆的框架（四段结构），081 有好传播的类比（点外卖），041 有明确的目标人群（小红书博主）。这三篇是本批里最具备「被主动转发」属性的。

**③ GitHub 生态（技术调性契合，零成本）**
建一个 `awesome-chinese-ai-tools` 仓库，或给已有的 awesome list 提 PR，在条目说明里引用我们的对比文章。GitHub README 的外链是 nofollow，但 awesome 类仓库被镜像站、导航站、博客大量转载，能产生二级链接——那些转载往往不加 nofollow。

**④ 工具官方的内容生态（成本仅为发邮件）**
国产 AI 工具厂商（智谱、月之暗面、秘塔等）多数在做内容生态，部分会收录优质第三方测评或接受投稿。转化率不高，但成本就是几封邮件。前提是文章质量确实过硬——本批的 009 和 039 是最有说服力的两篇。

**⑤ 真实问答场景（要有耐心，别做成垃圾链）**
搜索「豆包和kimi哪个好用」「ai生成ppt哪个好」这类词，找到问答社区里的真实提问，给出实质性回答后附来源链接。

**关键纪律：先在回答里给出完整答案，再放链接。** 只丢链接不给内容的会被删，而且会伤账号。这条投入产出比一般，但它同时是一种用户调研——你能直接看到真实用户是怎么问的。

**⑥ 免费站长工具提交（不是外链，但是收录前提）**
Google Search Console、Bing Webmaster Tools、百度搜索资源平台，全部免费，第一批上线后立刻提交 `sitemap.xml`。没有收录，前面所有优化都不产生任何作用。这条应该是**上线当天的第一件事**。

**明确不要做的：**
- ❌ 买链接、租链接
- ❌ PBN（私有博客网络）
- ❌ 批量目录站提交
- ❌ 博客评论区 / 论坛签名留链
- ❌ 友链交换群、站群互链

这些对 Google 是明确违规，对百度尤其容易被识别（中文低质外链的模式特征非常明显）。一个打算认真做 100 篇的站，没必要为了短期数字去背这个风险。

### 7.2 三个可以现在就做的省事办法

**① 大部分回补可以「预埋」，不用等**

`build_articles.py` 第 383-385 行有死链保护：

```python
if ln.get("slug"):
    target = ln["slug"]
    if target not in slug_index:   # 目标文章尚未产出时跳过，避免死链
        continue
```

所以**上表里所有 `slug:` 形式的回补，现在就可以直接写进 front-matter**。构建器会自动跳过未上线的，等目标文章一上线，下次构建自动生效——**不需要人回来改任何文件**。

这能把 26 条回补里的绝大部分变成零维护。建议本轮就把 009 / 025 / 039 / 052 / 081 这 5 个支柱页的全部卫星链接一次性预埋进去。

**② 只有正文内链需要真正的人工回补**

正文内链没有死链保护（`inline()` 不做存在性校验），所以正文内链**只能指向已上线页面**。上表里标「正文已点名」的三条（025 → 026/027/028）属于这一类：这些工具名已经出现在 025 的正文里，等对应测评上线后，直接在工具名上挂链接就行。这三条需要人工做，但每条只是加一对方括号。

**③ 触发时机固化成流程**

在 Brief 附录第 395 行「每批发布后必做」的基础上补一条：

> **每批构建完成后，重跑一次内链体检，检查上表中「触发批次 ≤ 当前批次」的条目是否已生效。** 预埋型自动生效，只需确认；正文型需手工执行。

如果实施了第 2.3 节的改动 C（构建期内链体检），这一步可以完全自动化——构建时直接打印哪些预埋链接本次被激活了。

## 第八部分：竞品差距分析

### 8.1 中文 AI 内容领域的链接结构现状

我按 Brief 里已经做过的 SERP 调研（第 217、236、255、274、293、312、331、350、369、388 行）逐类拆了竞品的链接结构：

**① 今日头条 / 百家号系内容农场（占据我们 5 个目标词的 SERP 首页）**

结构上的致命弱点：**平台根本不允许文章带外链，文章之间也没有作者可控的内链。** 它们的流量完全依赖平台推荐算法，一篇是一篇，彼此之间没有任何权重传递。

这意味着：**它们发 1000 篇也织不成一张网。** 每篇都是孤立节点，没有主题聚类，没有支柱页，没有权威度累积。它们能赢我们的只有一样——平台自身的域名权重。而这恰恰是随着我们的内容量和内链密度上升会被逐渐抵消的。

**② AI 工具导航站（AI 工具集、Futurepedia 中文版一类）**

结构是「首页 → 分类页 → 工具详情页」的严格树形。特征：
- 链接高度集中在导航层，分类页往下链，工具页**不回链**
- 工具详情页是纯叶子节点，内容通常只有一句话简介 + 一个跳出官网的外链
- **几乎没有内容页之间的横向链接**

它们的问题是内容深度撑不起长尾词——用户搜「豆包和kimi哪个好用」，导航站给不出答案。

**③ 厂商官网与软文站**

只链自己的产品页，锚文本几乎全是品牌词，导出链接大量指向付费页。用户价值低，且搜索引擎对这种自我指向的链接模式给的权重有限。

**④ 知乎 / CSDN 等 UGC 平台**

单篇质量可能很高（`大模型是什么` 的知乎高赞就很扎实），但**答案之间几乎没有内链**，主题聚类完全由平台标签决定，作者无法控制链接结构。而且知乎的长答案在移动端体验差——Brief 第 388 行提到的「800 字读完 vs 五千字长答案」就是这个差距。

**⑤ 少数认真做 SEO 的中文内容站**

会做文末「相关阅读」区块（和我们现在完全一样），但：
- 极少在正文内做上下文内链
- 几乎不挂外部权威来源（怕用户跳出）
- 锚文本重复率高

### 8.2 我们的四个结构性机会

**机会 1：正文上下文内链 —— 这条赛道几乎没人在跑**

头条系做不了（平台限制），导航站没内容可链，UGC 作者不会做，认真做 SEO 的中文站也普遍只做文末区块。

我们只要在 100 篇里每篇加 1-2 条正文内链，就能建立一个**竞品在结构上无法复制**的权重网络。对头条系是绝对不可能（平台不给权限），对导航站是内容量不够，对 UGC 是作者没有动机。

这是本次审计认定的**第一优势项**。成本：每篇一对方括号。

**机会 2：挂工具官网外链 —— 内容农场绝不会做**

它们的商业模式是留住用户看广告，链出去等于放走流量。我们反过来做，拿到三样东西：主题邻域信号、E-E-A-T 信任信号、「承诺可当场验证」的差异化。

尤其是 009「只收录打开就能用的」这个承诺——**给了官网链接，读者可以当场点开验证；不给，就只是一句自说自话。** Brief 第 255 行说竞品清单文的毛病是「把海外产品也列进去、不写免费额度、不标更新时间」，挂官网是第四个它们做不到的点。

**机会 3：支柱页 ↔ 卫星页双向闭环 —— 导航站只有单向**

导航站的分类页往下链工具页，工具页不回链，是单向树。我们做双向环，且同簇卫星之间横向互链。

以 C2 为例：009 ↔ 001、009 ↔ 002、001 ↔ 002，三个节点六条边，是完全图。等 003/004/005/092 补齐，C2 会有 7 个节点的高密度互链簇。**这个簇密度是导航站的数倍**，而且是它们的信息架构决定了做不到。

**机会 4：锚文本语义覆盖 —— 竞品全是品牌词或「点击查看」**

100 篇 × 5 条 = 500 条内链。如果每条锚文本都携带一个不同的长尾变体，等于**免费给全站做了 500 次关键词标注**。

举例：009 的长尾变体有「chatgpt平替国内」「国内能用的chatgpt」「不用翻墙的ai聊天工具」。用 3 种锚文本轮换，等于对 009 做了 3 个关键词的内部投票；用 1 种（现状），就只投了 1 个。

这个机会现在是**完全浪费掉的**——变体率 0%。但改起来只是改字符串，零成本。

### 8.3 必须诚实承认的劣势

不能只讲机会。我们相对竞品的真实短板：

| 劣势 | 严重度 | 能不能靠内链解决 |
|---|---|---|
| 零外链、新域名 | 🔴 致命 | **不能。** 内链只分配权重，不创造权重 |
| 无品牌搜索量 | 高 | 不能，靠内容分发慢慢积累 |
| 内容量 13 篇 vs 竞品平台数万篇 | 中 | 部分能——13 篇的高密度网 > 100 篇的孤立节点 |
| 无社交信号 | 中 | 不能 |
| 平台域名权重（头条/知乎） | 高 | 不能，只能靠主题深度错位竞争 |

**所以第 5.5 节的外链路径不是可选项，是必选项。** 内链架构做到 80 分之后，瓶颈就会立刻切换到外链上。我的判断是：**内链优化的边际收益在 80 分之后急剧递减，届时全部精力应该转向 5.5 节的第 ① 项（可被引用的数据资产）。**

### 8.4 结论

**我们在链接结构上唯一的、也是足够大的优势是：我们能控制整个站的链接图，而大部分竞品不能。**

头条系作者控制不了（平台限制）；知乎答主控制不了（平台限制）；导航站控制了但没内容可链；内容农场有内容但不愿意链出去。

**「能自主设计链接图」这件事本身就是护城河。** 这也是 Brief 第 24 行判断「聚类内链是这个站唯一的权重杠杆」的真正含义——它不只是「我们没别的办法了」，而是「这恰好是竞品结构上打不了的一张牌」。

前提是：**这张牌得真的打好。** 现在 42 分，说明还没打好。

### 规范 D：聚类链接规则

**D1. 簇内优先原则**
文末 4-5 条内链中，**至少 2 条必须是同簇**（支柱 + 兄弟）。

**D2. 跨簇上限 2 条 —— 附支柱页空窗期豁免**

> **豁免条款（本次审计新增，解决 039/052/081 的问题）**
>
> 当某支柱页所属簇的卫星文章尚未上线（「空窗期」）时：
> - 该支柱页的跨簇链接上限**临时放宽至 4 条**
> - 但**必须同时预埋本簇全部卫星的 slug**（构建器自动跳过）
> - 本簇第一篇卫星上线后，跨簇上限**收回至 2 条**，超出部分替换为簇内链接
>
> 理由：强行压跨簇数量只会让空窗期支柱页变成 1-2 条链接的贫链页，比跨簇更糟。放宽 + 强制预埋是更好的解。

**D3. 兄弟链接的选择标准**
同簇内选**语义最近**的 2 篇，不是随便挑两篇凑数。判断方法：这两篇的读者是不是同一批人、会不会连着读。

**D4. 测评↔教程配对必须双向**
Brief 第 54 行列的成对选题（NotebookLM 036/046、剪映 022/064、Suno 019/067、即梦 012/058、可灵 015/063、Cursor 029/077），**两篇必须互链**，且锚文本要体现意图差异：

- 教程 → 测评：锚文本用「哪个好 / 值不值得 / 怎么选」

这样既互相导流，又通过锚文本强化了两篇的意图区隔，**顺带防蚕食**。

**D5. 概念↔应用配对**
Brief 第 55-56 行列的拆分选题（AI 幻觉 055/083、提示词 052/053/084）同理，必须互链且锚文本区分意图。

### 规范 E：外链规则

**E1. 数量**：正文 2-3 条；对照表格内的工具官网不计配额。

**E2. 来源白名单（按优先级）**
1. 政府法规原文（`cac.gov.cn` 等 `.gov.cn`）
2. 工具官网 / 官方定价页 / 官方文档
3. 模型厂商官方技术文档（OpenAI / Anthropic / 阿里云 / 智谱等）
4. 学术论文（arXiv、期刊）
5. 国家标准、行业白皮书

**E3. 来源黑名单**
- ❌ 竞品内容站、AI 工具聚合站
- ❌ 今日头条 / 百家号 / 知乎回答 / CSDN 博客
- ❌ 任何无法确认时效性的二手转载
- ❌ 首页（要链具体页面，不要链首页）

**E4. `rel` 处理速查**

| 类型 | 写法 |
|---|---|
| 官网 / 官方文档 / 法规 / 论文 | `[锚文本](https://...)` → 构建器自动输出 `target="_blank" rel="noopener"`（dofollow） |
| 联盟 / 推广 / 返佣 | **必须** `rel="sponsored nofollow"`。约定：URL 末尾加 `#sponsored` 标记，构建器识别 |
| UGC / 不可控来源 | `rel="nofollow"`，且尽量不用 |

**E5. 时效性**：优先近 2 年内容。价格、免费额度类链接，写入前必须打开确认一次。

**E6. 死链预防**：外链每季度随 `verified` 字段更新时抽查一次。工具停服/改域名时按 slug 定位回改。
