## 二、P0 级问题（立即修复，影响收录）

### P0-1：tools.html 加载异常 — ~~已验证为误报~~

**原现象**：curl 请求返回空内容（HTTP 200 但 body 为空）

**实际原因**：Cloudflare Pages 的 clean URL 功能，`.html` 后缀会被自动 308 重定向到 `/tools`，非真正异常

**验证命令**：
```bash
# 检查 clean URL 是否正常
curl -s -o /dev/null -w "%{http_code}" "https://learntide.cc.cd/tools"
# 返回 200，正常

curl -s -o /dev/null -w "%{http_code}" "https://learntide.cc.cd/articles"
# 返回 200，正常
```

**结论**：无需修复，保持现状。

---

### P0-2：首页缺少描述性文本内容

**现状**：首页主要是导航 + 卡片网格，**<h1>下方无正文段落**

**问题**：搜索引擎无法判断网站主题定位，难以匹配相关查询

**修复方案**：在 hero 区域下方添加 1-2 段介绍性文字：
```html
<section class="site-intro">
  <h2>为什么选择 Learntide？</h2>
  <p>我们专注 AI 工具的中文评测与实操教程。每篇内容都经过实测验证，拒绝"云测评"——免费额度、国内可用性、真实价格都写清楚。</p>
</section>
```

**预期收益**：提升首页对"AI 工具评测""AI 教程"等核心词的排名机会。

## 三、P1 级问题（本周内修复，直接影响排名）

### P1-1：关键词密度系统性偏低

**数据**：qa_check 显示多数文章密度 0.68%-0.87%，目标应 ≥0.9%

**根因**：QA 检查只验证「主词出现 3 处」，未卡密度下限

**修复策略**：
1. 在新建稿件时，将关键词密度纳入 QA 硬性指标（≥0.9%）
2. 对现有文章按优先级分批优化（见附录 A）

**优化优先级排序**（基于搜索量预估）：
```
第一梯队（高搜索量）：
- ai-build-agent-guide（AI 智能体搭建）
- jianying-ai-tutorial（剪映 AI 教程）
- ai-avatar-generation-guide（AI 头像生成）

第二梯队（中搜索量）：
- ai-coding-assistants-compare（编程助手对比）
- what-is-prompt-engineering（提示词工程科普）
- ai-excel-tutorial（AI Excel 教程）
```

### P1-2：缺少 FAQ Schema 捕获精选摘要 — ~~已实现~~

**修复状态**：✅ 已完成（2026-08-24）

**实现方案**：
- 修改 `build_articles.py`，支持 `faq_questions` front-matter 字段
- 自动生成标准 `FAQPage` JSON-LD Schema
- 示例稿件：`drafts/ai-faq-schema-demo.md`

**使用方式**（新建稿件时添加）：
```yaml
faq_questions:
  - q: AI 智能体搭建需要编程基础吗？
    a: 不需要。扣子、Dify 等平台提供可视化拖拽界面...
  - q: 扣子完全免费吗？
    a: 免费版足以日常使用，每月提供充足 token 额度...
  - q: 搭建一个智能体要多久？
    a: 入门级助手 30 分钟即可上线...
```

**效果验证**：
```bash
# 检查生成的 HTML 是否包含 FAQ Schema
grep "FAQPage" articles/ai-faq-schema-demo.html
# 输出： "@type":"FAQPage",
```

**预期收益**：
- 每篇 FAQ 文章可捕获 2-5 个 Google「People Also Ask」位置
- 额外点击预估 +15%~30%

**建议**：
- 所有 `tutorial` 和 `list` 类型文章补充 FAQ Schema
- 优先处理高流量潜力文章（AI 智能体搭建、剪映教程、头像生成等）

### P1-3：文章标题模板单一，长尾覆盖不足

**现状**：标题多为「AI 工具名 + 怎么用/测评/对比」

**问题**：未覆盖用户真实搜索问句（如"有没有免费的 AI 修图工具"）

**优化方向**：
| 当前模板 | 优化方向 | 示例 |
|---------|---------|------|
| AI 头像生成教程 | 加入场景词 | AI 头像生成：5 款免费工具实测，微信头像 3 分钟搞定 |
| 豆包和 Kimi 对比 | 加入决策词 | 豆包 vs Kimi：选哪个？看这 3 个场景就够 |
| 扣子搭建入门 | 加入人群词 | 零基础也能会：扣子 AI 智能体搭建完全指南 |

## 四、P2 级问题（本月内优化，提升长期权重）

### P2-1：外链建设几乎为零

**现状分析**：
- 内部外链：2 条/篇，均为官网/权威域（openai.com, anthropic.com）✅
- 外部反向链接：估计 <10 条，均来自百家号/百度知道引流 ✅

**差距**：同行站点（如机器之心、量子位）外链量级为数百至数千

**执行策略**（分阶段）：

#### 第一阶段：内容资产型外链（1-2 个月）
- 制作「AI 工具年度测评白皮书」PDF，投稿至 CSDN/掘金
- 制作「AI 工具价格对比表」，发布至知乎专栏
- 每篇报告含 Learntide 原文链接，获取自然引用

#### 第二阶段：主动 outreach（2-3 个月）
- 整理 50 个 AI 垂直媒体联系方式（36氪、新智元、虎嗅等）
- 针对每篇深度内容发送 Press Release
- 目标：每月获取 5-10 条高质量外链

#### 第三阶段：社区参与（持续）
- 在 V2EX、即刻、Reddit r/LocalLLaMA 分享有价值的技术分析
- 避免硬广，以"分享经验"角度自然带链接

### P2-2：缺少数据驱动的原创内容

**现状**：220 篇文章均为"工具介绍/教程/对比"，**无一手数据**

**机会**：数据驱动内容可获得 3-5 倍外链增益（Ahrefs 数据）

**建议选题方向**：
1. 「2026 AI 工具价格大盘点：XX 款工具免费额度对比」
2. 「AI 绘图工具质量测试：同一 Prompt 下 Midjourney vs 即梦 vs DALL-E 3」
3. 「中国用户最常用的 10 个 AI 工具：基于 10 万份问卷调研」

### P2-3：时效性内容更新频率低

**现状**：最新文章发布日期为 2026-08-24，但大部分文章 lastmod 为 08-06~08-14

**问题**：Google 对内容新鲜度敏感，长时间无更新会降低站点活跃度评分

**优化方案**：
1. 建立「月度更新机制」：每月选择 10-20 篇热门文章补充最新信息
2. 在 sitemap 中为旧文章添加新的 lastmod 日期触发重抓
3. 创建「AI 新闻简报」页面，每周更新行业动态（新增轻量页面）

### P2-4：Social Signals 未利用

**现状**：仅百家号/百度知道引流，**未激活**：
- 微信公众号（内容矩阵）
- 小红书（图文种草）
- 即刻/Twitter（技术圈层）
- LinkedIn（职场人群）

**策略**：优先选择 2-3 个平台深度运营，而非全平台浅尝辄止

**建议优先级**：
1. 小红书（已认证账号「工位旁的小绿植」）→ 图文种草 + 引流百度网盘
2. 即刻 → 技术圈层影响力 + 精准用户
3. 微信公众号 → 深度内容沉淀 + 订阅转化

## 附录 B：FAQ Schema 模板

**标准 FAQ 结构**（适用于教程类）：
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "XXX 是什么？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "一段简洁的回答（50-80 字）"
      }
    },
    {
      "@type": "Question",
      "name": "XXX 怎么用？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "第一步...第二步...第三步..."
      }
    },
    {
      "@type": "Question",
      "name": "XXX 免费吗？",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "明确说明免费额度/收费模式"
      }
    }
  ]
}
```
