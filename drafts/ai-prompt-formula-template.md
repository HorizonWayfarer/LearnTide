## 提示词模板公式：一个公式打底

提示词不需要背一百条技巧，一个提示词模板公式就够了：角色 ＋ 任务 ＋ 背景 ＋ 格式 ＋ 约束。记不住每段结构背后的原理？先看这篇 [AI 提示词怎么写](how-to-write-ai-prompts.html) 讲每段为什么重要，这里直接给公式的裸模板，拿走就能用：

```
你是【角色】。请帮我【任务】。
背景：【背景信息与限制条件】
输出格式：【列表 / 表格 / 分段，字数要求】
注意：【不要做什么】
```

把【】里的内容换成你自己的需求，就是一条完整的提示词。

## 把一句话需求改写成好指令：三步改写法

第一步，补角色。你原来的指令「帮我写个总结」，缺角色。AI 不知道该用什么身份回答，就会按最通用的口径来。补上「你是擅长提炼要点的编辑」，AI 立刻换一种方式输出，用词更精准、结构更清晰。第二步，补背景与约束。读者是谁、用在哪、有什么限制。补了背景，AI 就不会猜。比如，「帮我写个活动方案」改成「帮我写一个面向年轻用户的线下活动方案，预算两万以内，周六下午办」，结果完全不同。第三步，指定格式。几段、几条、表格还是清单，写清楚就不用返工。每补一步，输出质量都上一个台阶。三步走完，你能明显感觉到 AI 的输出从「像是 AI 写的」变成了「像是为你写的」。

## 四个高频场景的现成公式

场景一：写作

```
你是【领域专家】。请帮我写一篇关于【主题】的【文体】。
背景：读者是【目标读者】，需要【什么信息】。
输出格式：分【N】段，每段控制在【N】字以内。
注意：不要用「首先」「其次」「综上所述」这类套话。
```

场景二：总结

```
你是一位擅长提炼要点的编辑。请把下面的内容总结成 5 条要点。
背景：读者是没有相关背景的同事，需要快速了解结论。
输出格式：编号列表，每条不超过 30 字，先结论后原因。
注意：不要加入原文没有的信息，不确定的地方标注出来。
```

场景三：分析

```
你是一位【领域】分析师。请分析下面的【数据/材料】。
背景：分析结论将在【场景】中使用。
要求：先列事实，再给判断，明确区分两者。
注意：不要过度解读，没有数据支撑的推论要标注出来。
```

场景四：改错

```
你是一位【中文/英文】编辑。请修改下面的文本。
要求：1) 只改语法、拼写、搭配和标点，保留原意；
2) 输出修改后的全文；
3) 用表格列出每一处改了什么、为什么改。
原文：【粘贴】
```

## 公式怎么微调

加例子。贴一段你认可的样例，说「照这个风格写」，比用十个形容词描述风格有效得多。你说「专业一点」，它可能还你一堆书面语；你贴一段样例，它照着仿，结果更接近你想要的效果。加否定。明确写出不要什么，比如「不要用『综上所述』」「不要出现没有出处的数字」。负面约束往往比正面要求更好使，因为 AI 倾向于过度使用通用措辞，加否定能直接剪掉这个倾向。加分步。要求「先列提纲，我确认后再写正文」，分两步走，能在半路纠偏，避免它一口气写完两千字全跑偏。这三个加法不挑工具，在哪款 AI 上都成立。

## 什么时候不用套公式

简单问题别套公式。查一个词的意思、换算单位、问某年发生了什么，直接问就行。套公式只会让 AI 拉长回答、绕圈子，反而降低了效率。判断标准很简单：如果答案只有一个标准形态，直接问；如果答案有很多种写法、需要贴合你的具体处境，才值得用提示词模板公式。另外，这套公式针对对话类 AI，图像生成工具的提示词是另一套结构，不能套用。

最后说一句反的：**别把公式当咒语。** 套完不看输出、不迭代，等于没用。公式解决的是「说清楚」，不解决「你自己也没想清楚要什么」。
