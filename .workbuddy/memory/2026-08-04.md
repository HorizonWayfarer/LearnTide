## v1 关键 Bug 修复：四个 HTML 文件都缺 `<link rel="stylesheet">`

- 伟超反馈"v1 实在是太难看了"——但根本原因不是"设计粗糙"，而是 **CSS 根本没接上**：我交付的四个 HTML 文件（index/tools/about/article）head 里都漏写了 `<link rel="stylesheet" href="...">`，所以页面渲染成浏览器裸默认样式。style.css 本身写好了，没生效。
- 教训：每次交付 HTML + CSS 的项目，**最后必须 grep 验证 `<link rel="stylesheet"` 在每个 HTML 里都存在**，不能凭印象。
- 已修复：四个文件并行 Edit 补链接。
  - index/tools/about：`href="assets/style.css"`
  - articles/ai-weekly-report-guide：`href="../assets/style.css"`（在子目录，路径要回退）
- 修复后重截图确认：CSS 已加载，首页/工具页呈现完整水木浅色主题。伟超本地预览现在也是样式正常的版本。
