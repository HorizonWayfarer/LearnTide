# 研究 Brief：jimeng-prompt-tips

**编号 058｜栏目：使用教程｜聚类：C5 视频创作｜标题：即梦 AI 提示词技巧：中文出图更准**

**1. 主关键词与字数**
- 主词：即梦提示词技巧｜难度：中（头条系长文与 AI 导航站手册页占位，"万能公式"已被写烂；但"**中文特有的坑**"这个角度基本无人做）｜建议字数：800–900（tutorial 档）

**2. 语义变体 / 长尾**
即梦怎么写提示词、即梦出图技巧、即梦ai教程、即梦提示词公式、即梦垫图怎么用、即梦生成的图不像怎么办

**3. 搜索意图**
信息型。真实问题：①我写了一句话出来的图跟想的完全不一样，怎么办；②提示词到底按什么顺序写、写多长；③负面提示词怎么写（手指畸形、变形）；④中文和英文该怎么混；⑤有没有能直接抄的模板。

**4. 竞品 Top 10 基准**
- 即梦官网/官方手册页：入口页，无教学纵深
- 今日头条长文（多篇，占位强）："万能公式（主体+动作+环境+光线+风格+构图）" + 反面/正面教材对照 + 风格模板，**质量不错，是主要正面竞品**
- 青瓜传媒等运营站"即梦 5.0 提示词完整实操"：公式 + 参数值 + 问题修复清单，信息密度高但**硬报参数数字（风格强度 0.65–0.75 等），易过期**
- AI 导航站"提示词手册"页：方法论罗列，抽象
- 小红书图文：单点技巧，碎片化
- 字数基准：1500–2500
- **内容差距（我们要补的，标题已经点明主攻方向）**：
  ① **【核心】"中文出图更准"要真的兑现 —— 讲清中文提示词特有的坑**，这是所有竞品的空白（最多一篇提了句"中英结合"）：
     - **哪些词用中文最准**：主体、场景、动作、国内地标与本土文化意象（旗袍、胡同、国潮、水墨留白）—— 即梦是中文原生模型，这是它相对 Midjourney 的真实优势位
     - **哪些词建议用英文**：摄影与光影术语（85mm lens、cinematic lighting、bokeh、rim light）、画质词 —— 中文对应词识别率不稳
     - **中文特有的失手点**：① 成语/古诗/抽象意境（"意境悠远""禅意"）容易被理解成字面画面；② 数量词（"三个人""一对情侣"）经常出错，要用画面语言兜；③ 一句话堆多种风格（"莫奈风+赛博朋克+国风"）→ 风格互相打架；④ 否定式中文（"不要有人"）不如放进负面提示词
     - **中文文字上图**（海报标题/文案）是即梦的相对强项，给写法
  ② **"写不准就垫图"这条捷径要前置**：竞品把垫图当进阶功能放在后面，实际上对新手它比调提示词有效得多（构图/风格/人物一致性）。我们把它提前，符合"务实"调性。
  ③ **参数不硬编数字**：风格强度、相似度等一律讲"低/中/高分别对应什么效果"+ [待核实]，避免版本更新即过期（竞品最大的腐坏点）。
  ④ **"出图不对怎么修"的对症表**：脸/手畸形、画面发灰、和描述不符、背景杂乱、文字乱码 —— 每种给一条具体改法。这种"问题 → 动作"的映射最实用，也最易被引用。
  ⑤ **可直接复制的模板**（品牌资产）：给 3 条完整可粘贴的中文提示词（人像写实 / 电商产品图 / 国风海报），改主体即可用。
- 精选摘要机会：有。"即梦提示词怎么写"适合做公式 + 一条完整示例的直答段。

**5. 推荐大纲**
- H1：即梦 AI 提示词技巧：中文出图更准
- 开头（直答段）：给公式一句话 + 一条完整可复制示例，让读者立刻能用。
- H2 提示词的基本骨架（主体 → 动作/状态 → 环境 → 光线 → 风格 → 构图；说明"至少写满前四项"，并给一个反面 vs 正面对照）
- H2 中文怎么写才准（**核心章节**：哪些用中文、哪些用英文、四个中文特有失手点及改法）
- H2 负面提示词怎么写（人像 / 商品 / 通用三组，可复制）
- H2 写不准就垫图：比调词更快的一条路（用途：固定构图、固定风格、固定人物；相似度高低的效果差异 [待核实]）
- H2 三条可直接抄的模板（人像写实 / 电商产品图 / 国风海报）
- H2 出图不对怎么修（**对症表**：畸形 / 发灰 / 不符 / 背景杂乱 / 文字乱码 → 各一条改法）
- 结尾：一句话建议 + 相关阅读
