# 百度知道养号计划（文笔不高也能答）

> 适用阶段：账号刚因「AI 工具推荐类」回答被删 3 条，处于风控敏感期。
> 目标：先养 10–15 个普通、非营销类回答，恢复账号信誉，再启动 bzd-01 自动引流。

---

## 一、先卸下心事：百度知道不看文笔

你那 3 条被删，**不是因为文笔差，是因为「AI 工具推荐/对比」本身就是百度知道定义的广告营销高危区**。

高采纳回答的共性只有三条，跟文笔半毛钱关系没有：

1. **真经历过** —— 有细节、有画面，不像抄的
2. **不绕弯** —— 第一句就给结论，别铺垫
3. **像真人** —— 有口语词、有失败经历、不八股

反过来，**文笔太好反而危险**：结构工整、词汇华丽、满篇「首先/其次/综上所述」，系统一眼判成模板稿/AI 生成/营销稿。所以你文笔普通，正好。

---

## 二、你只要会「填空」

下面三个模板，复制后把 `[ ]` 改成你自己的事就能发。**别追求文采，填真实细节就行。**

### 模板1 · 经历型（最推荐，最像真人）

```
我之前也遇到过这个。当时 [简单说下场景，比如：去年双十一买完东西]，
搞了半天没搞定。后来我是这么弄的：
第一步，[具体动作1]；
第二步，[具体动作2]；
中间 [某步] 容易踩坑，要注意 [提醒]。
现在 [结果，比如：再没出过问题]。希望能帮到你。
```

### 模板2 · 步骤型（适合「怎么弄/怎么办」类问题）

```
这个不难，按顺序来就行：
1. 先 [动作1]；
2. 然后 [动作2]，这步别选错 [选项/位置]；
3. 最后 [动作3]。
要是 [某情况] 就 [补充处理]。我试过，基本一次成。
```

### 模板3 · 选择型（适合「XX 和 YY 哪个好」类问题——注意：只说用法，不推荐品牌）

```
看你怎么用。如果 [场景A]，那就 [选法X]；
如果 [场景B]，[选法Y] 更顺手。
我平时 [说下自己的实际用法]，感觉够用了。
```

## 三、填空的「细节」从哪来（你唯一要动脑的地方）

细节不是文笔，是**具体信息**。回答里塞进下面任意两三条，可信度立刻拉满：

- **数字**：用了 3 个月 / 试了 5 次 / 花了一下午
- **时间**：去年 / 上周 / 前天 / 双十一
- **场景**：在家 / 在公司 / 出差路上
- **失败**：我一开始也搞错了，后来才发现……
- **口语词**：说实话 / 其实 / 我觉着 / 说白了

> 例：「我前天刚弄完，搞了差不多两小时，一开始点错了地方，后来才发现要先把 XX 关掉」——这种比「首先打开设置，其次选择选项」可信 10 倍。

## 四、选哪些题答（⚠️ 养号期避开 AI 工具 / 软件推荐！）

账号刚被删的就是这类，现在碰就是送。下面这些**安全、高搜索、靠真实经验就能答**，挑你真懂的：

### 【生活常识】
- 搜索词：「XX 怎么保存 / 小妙招 / 为什么 XX」
- 你能答的：食物储存、衣服去渍、居家收纳、省钱小技巧

### 【学习 / 考试方法】（非 AI）
- 搜索词：「英语口语怎么练 / 怎么高效记笔记 / 考研怎么安排」
- 你能答的：你自己的学习/工作方法、信息整理习惯

### 【数码使用技巧】（只讲「怎么用」，不推荐买啥）
- 搜索词：「Windows XX 功能怎么用 / 微信电脑版 XX / 文件怎么批量改名」
- 你能答的：你日常用电脑的真实技巧（你本来就是玩自动化的）

### 【游戏 / 兴趣】
- 搜索词：「XX 游戏 XX 关卡怎么过 / XX 怎么做」
- 你能答的：你真玩过的、真琢磨过的

### 【职场 / 自由职业经验】
- 搜索词：「远程工作怎么找 / 自由职业要注意什么 / 简历怎么写」
- 你能答的：你做内容站、搞副业的真实体会（**只谈经验，不提 Learntide、不引流**）

### 【美食 / 日常】
- 搜索词：「XX 怎么做 / XX 的家常做法」
- 你能答的：你会做的菜、踩过的坑

> 挑题铁律：**只答你真经历过/真懂的**。不会就划走，别硬编——编出来的没有细节，反而像营销。

## 五、每日节奏

- 每天 **2–3 个**，答完就停，**隔 1 天**再答下一批
- **混着类答**：今天生活、明天学习、后天数码，别连答同类
- 答完回去看一眼有没有被推荐/采纳，被采纳的说明方向对

## 六、红线（碰了就前功尽弃）

- ❌ 不答**医疗诊断 / 法律 / 投资**类（容易违规 + 惹麻烦）
- ❌ 回答里**不出现任何品牌名、链接、二维码、"搜 XXX"**
- ❌ **不连答同类问题**（尤其 AI 工具 / 软件推荐，现在绝对禁区）
- ❌ **不把同一条答案复制去答多个问题**（系统必判灌水）
- ❌ 不出现「首先/其次/综上所述/总而言之」这种八股连接词

## 七、什么时候能开始 bzd-01 引流

1. 养满 **10–15 个**普通回答

3. 账号有了一些**采纳 / 等级提升**

## 九、匿名回答策略（伟超 21:19 提问）

- **养号期默认不开匿名（实名答）**。理由：①养号要堆的是这个账号的采纳/等级/活跃权重，实名才能累积；匿名经验照给但账号曝光与"正常老用户"感堆不起来。②风控看账号行为（设备/频率/IP/内容）不看显示名，匿名规避不了风控，系统后台仍归因到本号。③养号期技术经验类回答不涉及真实姓名/住址，无隐私风险。
- **唯一开匿名的场景**：回答内容特别个人隐私化（收入/家庭/具体身份）时才勾。技术题（只读文件/换网卡等）均不需。
- `zhidao.py` 匿名 checkbox `input[name="md"]` 默认不勾，与此策略一致。

> **关于红线「不出现品牌名」的澄清**：该条指**不得出于推广目的主动带品牌**（如"推荐你用XX""XX最好用"）。真实经历中必然提及的品牌（如换网卡提及 Intel/Realtek/华硕）可如实写，但须铺垫"我用的/我选的"而非"推荐你买"，且整篇不得出现价格对比引导购买、链接、二维码。第二题「电脑怎么更换wifi」即此情形，已放行。
